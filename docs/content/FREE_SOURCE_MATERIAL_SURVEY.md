# Free public-domain source material survey

Reference doc so future content sessions don't re-research from scratch.
All FSI ("Foreign Service Institute") materials are genuine US government
public domain works — no attribution burden, no licensing risk. Mandatory
modernization pass still applies to all of these per
`docs/content/AUTHORING_GUIDE.md` §10 (1960s-70s register, never import
verbatim). "Verified" means an actual course-description page was read
this pass, not just a title in an index; "listed only" means it appears
on a distributor's language index but wasn't individually checked.

**Known trap, don't repeat it**: an earlier Dutch search found a "Refresher
Course" that turned out to be intermediate/advanced, not beginner — always
open the actual course description page and check for explicit
level/audience language ("basic-level," "useful control of the structure,"
"for diplomats with no prior knowledge" etc.) before committing authoring
time to a source, title/branding alone ("Basic Course") is suggestive but
not proof.
